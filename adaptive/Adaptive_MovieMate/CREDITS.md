# Credits and sources

- Recommender models (`models.py`, `data.py`) are reused from the author's earlier MovieMate project
  (Ghorpade, 2026). That project credits the public notebook item-based-collaborative-filtering by
  vishwajeet-hogale (n.d.), and the item-based idea of Sarwar et al. (2001).
- The adaptation design follows the guidelines of Amershi et al. (2019): learn from user behavior,
  change cautiously, explain changes, and give users control.
- The genre-level Thompson sampling is written for this project from the standard Beta-Bernoulli
  formulation; no code was copied from another source.
- MovieLens ml-latest-small: GroupLens Research (n.d.); Harper & Konstan (2015). The dataset is not
  redistributed here.
- AI assistance: an AI assistant (Anthropic, 2026) helped draft code, tests, and documentation. The
  author reviewed and ran all code and checked all sources.
